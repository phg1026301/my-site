# my-site

순수 HTML, CSS, JavaScript로 만든 홍길동의 자기소개 웹사이트입니다.

## 배포 주소

https://phg1026301.github.io/my-site/

## 로컬에서 보기

빌드나 설치 과정 없이 바로 볼 수 있습니다.

1. 이 저장소를 내려받습니다.
2. 폴더 안의 `index.html`을 더블클릭해 브라우저로 엽니다.

로컬 서버로 보고 싶다면 폴더에서 아래 명령 중 하나를 실행한 뒤 http://localhost:8000 에 접속하세요.

```bash
# Python이 설치되어 있다면
python -m http.server 8000

# Node.js가 설치되어 있다면
npx serve -l 8000
```
